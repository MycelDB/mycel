# `mycel domain`

Manage client-visible domains inside a space.

Authentication mode: **user**.

## Common tasks

- List/create/show/update/delete domains.

## Examples

```sh
mycel domain list --space-id <space-id>
```

```sh
mycel domain add notes --space-id <space-id>
```
