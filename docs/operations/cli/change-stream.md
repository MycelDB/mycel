# `mycel change-stream`

Watch graph changes for a domain.

Authentication mode: **user**.

## Common tasks

- Subscribe to domain change events.
- Resume from a revision where supported.

## Examples

```sh
mycel change-stream watch --space-id <space-id> --domain-id <domain-id>
```
