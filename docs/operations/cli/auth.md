# `mycel auth`

Principal login, refresh, logout, whoami, and auth-session management.

Authentication mode: **principal**.

## Common tasks

- Login and refresh principal auth sessions.
- List or revoke auth sessions.

## Examples

```sh
mycel auth whoami
```

```sh
mycel auth session list
```
