# `mycel auth`

Standard-user login, refresh, logout, whoami, and session management.

Authentication mode: **user**.

## Common tasks

- Login and refresh standard-user sessions.
- List or revoke auth sessions.

## Examples

```sh
mycel auth whoami
```

```sh
mycel auth session list
```
