# `mycel semantic`

Manage semantic indexes, search, and maintenance.

Authentication mode: **mixed**.

## Common tasks

- Search semantic indexes as a user.
- Manage indexes and maintenance as an operator.

## Examples

```sh
mycel semantic search --space-id <space-id> --domain <key> "query text"
```
