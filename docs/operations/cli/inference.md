# `mycel inference`

Configure inference/model/vector/credential admin resources.

Authentication mode: **operator**.

## Common tasks

- Apply inference packages.
- Manage model endpoints, models, vector stores, credentials, grants, and policies.

## Examples

```sh
mycel inference packages list
```
