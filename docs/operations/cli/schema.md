# `mycel schema`

Manage domain-scoped graph schemas.

Authentication mode: **user**.

## Common tasks

- Get/put/delete domain schemas.
- Validate schema documents and graphs.

## Examples

```sh
mycel schema get --domain-id <domain-id>
```

```sh
mycel schema put --domain-id <domain-id> --file schema.gwl
```
