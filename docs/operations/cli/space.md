# `mycel space`

Manage spaces.

Authentication mode: **mixed**.

## Common tasks

- Create/delete spaces as an operator.
- List/show visible spaces as a user.

## Examples

```sh
mycel space list
```

```sh
mycel space add "Notes" --owner-username alice
```
