# Implementation Plan Reclassification Audit

This audit records the `docs/implementation/unreleased/` cleanup for MycelDB/mycel#135.

Method: for each document, inspect `git log --follow` history and the earliest release tag containing the substantive implementation/history commit. Patch tags such as `v0.7.4` and `v0.16.1` are intentionally collapsed into their minor-version buckets (`v0.7`, `v0.16`). Documents with residual follow-up notes are archived with the release family that shipped the corresponding implementation; active follow-up work should be tracked by GitHub issues rather than by keeping historical plans in `unreleased/`.

## Summary

- Archived shipped or superseded historical plans into minor-version buckets from `v0.7` through `v0.17`.
- Retained only the AdminTemplateService / Console template UI plan in `unreleased/`, because the audit found no generated or daemon service implementation for `AdminTemplateService`.
- Did not create patch-version buckets; patch-release evidence is associated with the corresponding minor bucket.
